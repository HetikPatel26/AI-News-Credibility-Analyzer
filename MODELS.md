# Model Files

The trained models are **not included in this GitHub repository** because the complete model directory is approximately **1 GB**, which exceeds GitHub's recommended repository size.

To run the project, place the following files inside the `models/` folder:

```
models/
├── logistic_regression.pkl
├── random_forest.pkl
├── tfidf_vectorizer.pkl
└── distilbert_model/
```

Folder structure:

```
AI-News-Credibility-Analyzer/
│
├── models/
│   ├── logistic_regression.pkl
│   ├── random_forest.pkl
│   ├── tfidf_vectorizer.pkl
│   └── distilbert_model/
│
├── streamlit_app/
├── README.md
└── requirements.txt
```

The models were trained locally and are available with the project submission/demo version.
